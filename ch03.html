Chapter 03

聚散度關係

The Vergence Relationship

這是全書最重要的一句話：光學面做的事，就是把屈光力「加」到光的聚散度上。進來多少、加多少、出去就是多少。

學習目標 GOALS

  • 理解「入射聚散度 + 屈光力 = 出射聚散度」的意義，並能預測像的位置變化方向。
  • 理解聚散度會隨光行進而連續改變，只有在通過光學面時才會「跳」一下。
  • 理解聚散度與介質折射率有關，並能解釋水中物體為什麼看起來比較淺。

核心觀念 KEY IDEAS

L′ = L + F

聚散度相加

物體送來的光有聚散度 L（通常是負的發散光），光學面加上它的屈光力 F，射出的光聚散度就是 L′。

Sign of L′

L′ 的正負決定實像或虛像

L′ 為正：光會聚 → 實像在右側。L′ 為負：光仍發散 → 虛像在左側。L′ 為 0：平行光，像在無限遠。

Reduced vergence

聚散度要乘上折射率

L = n / l。同樣距離，在折射率高的介質中，聚散度數值較大。

Linear sign convention

直線符號慣例

以光學面為原點，光由左向右行進；在右邊的距離為正，在左邊為負。

互動實驗 LAB

LAB 3-1

聚散度軌跡：光一路走、一路變

拖曳物點

表面屈光力不變，把物體從 25 cm 拉到 50 cm（更遠），像會往哪裡移動？

物體越遠，入射光越不發散（L 從 −4 D 變成 −2 D），加上同樣的 +10 D 後 L′ 變大（+6 → +8 D），聚散度越大代表像越近。

觀察重點

  • 下方圖：左段是發散光（負），越走越接近 0；在表面處「跳」了 F；右段會聚光越走越大，在像點趨向無限大。
  • 把 F 調成負值，觀察 L′ 仍為負，像變成虛像（在左側）。
  • 只改 n′：同樣的 L′，在折射率高的介質中，像距較遠（l′ = n′ / L′）。

平面折射與視深（apparent depth）

平面屈光力0.00 D

從空氣中往下看水底 1 m 深的硬幣，它看起來在多深？

平面的屈光力是 0，所以聚散度不變（L′ = L），但聚散度 = n / l。從 n = 1.333 換到 n′ = 1.000，距離必須按比例縮短：約 75 cm。

觀察重點

  • 平面沒有屈光力，卻還是讓物體「看起來」變近，原因是聚散度要乘上折射率。
  • 介質折射率越高，物體看起來越淺（鑽石中的物體只剩約 41% 深）。
  • 臨床例子：從外面看，房水後方的虹膜與瞳孔看起來比實際位置更靠前。

常見迷思 MISCONCEPTIONS

平面沒有屈光力，所以對光完全沒有影響。
平面不改變聚散度，但折射率改變後，相同的聚散度對應不同的距離，所以物體看起來的位置會改變（視深）。
L′ 越大，像越遠。
相反。聚散度是距離的倒數，L′ 越大代表光越快會聚，像越靠近表面。
放大率是像距除以物距，跟折射率無關。
兩側介質不同時，放大率應該用聚散度比 L / L′ 來算，這已經把折射率考慮進去了。

公式補充 OPTIONAL

展開看公式（選讀）

物、像聚散度：L = n / l　L′ = n′ / l′

橫向放大率：M = L / L′
