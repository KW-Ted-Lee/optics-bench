Chapter 01

基本名詞與觀念

Basic Terms and Concepts

整本光學的共同語言只有一個：聚散度（vergence）。這一章先建立「光線、光束、波前」的圖像，再看光在兩種介質交界處怎麼轉彎。

學習目標 GOALS

  • 能分辨發散、會聚、平行三種光束，並說出它們聚散度的正負號。
  • 理解聚散度描述的是「波前有多彎」，而且會隨光行進的距離改變。
  • 能用折射率高低判斷光線偏向或偏離法線，並說明全內反射發生的條件。

核心觀念 KEY IDEAS

Ray · Pencil · Wavefront

光線、光束與波前

點光源向四面八方發出光，同時往外推進的「等相位面」就是波前。光線是垂直於波前的箭頭，一小束光線稱為光束（pencil）。

Vergence

聚散度＝波前的彎曲程度

離點光源越近，波前越彎；越遠，越平。聚散度就是到焦點距離（公尺）的倒數，單位是屈光度 D。

Sign

正負號代表方向，不代表強弱

發散光為負，會聚光為正，平行光為零。−5 D 和 +5 D 彎曲程度相同，只是方向相反。

Refraction

折射：速度改變造成轉彎

折射率 n＝真空光速 ÷ 介質中光速。光從低 n 進入高 n 會偏向法線；從高 n 進入低 n 會偏離法線。

觀察面從 25 cm 移到 50 cm（距離加倍），聚散度大小會怎樣？

聚散度是距離的倒數。距離加倍，波前變平一半：−4.00 D → −2.00 D。拉到 100 cm 再看看，曲線越來越平緩，這就是為什麼 6 公尺外就可以視為「光學無限遠」。

觀察重點

  • 靠近光源時，稍微移動一點點，聚散度就大幅變化（下方曲線很陡）；遠離光源後幾乎不變。
  • 切到「會聚」：光束朝像點收斂，聚散度為正，越接近像點數值越大。
  • 切到「平行」：波前是直線，聚散度為 0，與距離無關。

光從鑽石（n = 2.42）射向空氣，入射角 30°，會發生什麼？

鑽石對空氣的臨界角只有約 24.4°。入射角 30° 已超過臨界角，光無法射出，全部反射回鑽石內。這正是鑽石閃亮的原因。請把上方設為鑽石、下方設為空氣驗證。

觀察重點

  • 入射角 0°（沿法線入射）時，光線不轉彎，只有速度改變。
  • 低 n → 高 n：折射光偏向法線。高 n → 低 n：偏離法線，入射角再加大就會全內反射。
  • 兩種介質折射率差越大，轉彎越明顯；折射率相同時完全不轉彎。

常見迷思 MISCONCEPTIONS

聚散度越大，代表光越亮。
聚散度只描述波前彎曲的程度和方向，和亮度無關。一盞很亮的燈放在 2 公尺外，聚散度只有 −0.50 D。
負的聚散度代表光比較「弱」。
正負號只代表方向：負＝發散，正＝會聚。−5.00 D 的發散光和 +5.00 D 的會聚光彎曲程度一樣大。
光進入高折射率的材料一定會轉彎。
沿法線（入射角 0°）進入時不會轉彎，只是速度變慢。轉彎需要「斜著」通過界面。
從 6 公尺外來的光聚散度一定是 0。
嚴格說是 −0.17 D，只是非常小，臨床上把 6 m（20 ft）當作光學無限遠。真正的 0 D 只有無限遠的物體才有。

公式補充 OPTIONAL

展開看公式（選讀，理解觀念後再看）

聚散度：L = n / l　l 是到點光源或像點的距離（公尺），n 是光所在介質的折射率。

折射率：n = c / v

斯涅爾定律：n sin θ = n′ sin θ′

臨界角：sin θc = n′ / n（只在 n > n′ 時存在）
