Chapter 05

多面光學系統

Optical Systems with Multiple Surfaces

眼睛、厚鏡片、望遠鏡，都是好幾個光學面排在一起。方法只有一個：一面一面來，前一面的像，就是下一面的物。

學習目標 GOALS

  • 理解「前一個光學面的像 = 下一個光學面的物」的接力原則。
  • 理解光在兩個光學面之間行進時，聚散度會改變。
  • 能辨認虛物（virtual object）：還沒會聚完成就被下一面攔截的光。

核心觀念 KEY IDEAS

Step by step

接力成像

第一面產生中間像，它就變成第二面的物。每一面都用 L′ = L + F。

Vergence changes with distance

走一段路，聚散度就變

第一面射出的聚散度，走到第二面時已經不一樣了。會聚光越走越會聚，發散光越走越平。

Virtual object

虛物

會聚光在形成像之前就碰到下一面，這個「本來要形成的像」就是虛物，入射聚散度為正。

Total magnification

總放大率相乘

系統總放大率等於每一面放大率相乘。兩次倒立就變回正立。

互動實驗 LAB

LAB 5-1

雙透鏡接力成像

拖曳物體或第二片透鏡

把兩片間距縮小到 20 cm，讓第二片透鏡擋在中間像「之前」。第二片透鏡收到的光是？

光還在會聚途中就被第二片攔截，入射聚散度為正。中間像沒有真正形成，它是第二片透鏡的「虛物」，位在第二片的右側。

觀察重點

  • 聚散度帳本：「跳」是透鏡加上屈光力，「走」是光在空氣中行進造成的變化。
  • 下方軌跡圖中，兩片透鏡之間的線段會一路改變，不是一個固定值。
  • 兩片正透鏡各成一次倒立實像，最後的像會變回正立。

兩面都是正的，鏡片變厚後，平行光的焦點會比薄透鏡預測的？

光在玻璃內已經在會聚，走過厚度 t 之後聚散度變得更大，再加上後表面的屈光力，總效果更強，焦點更靠近。

觀察重點

  • t = 0 時實際焦點與薄透鏡預測重合；厚度越大，兩者差距越明顯。
  • 玻璃中的光線（n = 1.5）在兩面之間是會聚的，這段路讓聚散度改變。
  • 這就是第 6 章「後頂點屈光力」與「等效屈光力」的由來。

常見迷思 MISCONCEPTIONS

兩片透鏡貼在一起或分開一點，屈光力都是相加。
只有貼在一起（間距為 0）時才能直接相加。分開後，光在中間行進時聚散度會變，總效果也跟著改變。
虛物就是虛像。
虛物是「射向下一面的會聚光原本要形成的點」，在該面的右側；虛像則是射出光的延長線交點。兩者都不是光真的抵達的地方，但角色不同。
光在玻璃裡的聚散度只要用距離倒數就好。
在折射率 n 的介質中，聚散度 = n / 距離。計算行進時要用「約化距離」t / n。

公式補充 OPTIONAL

展開看公式（選讀）

每一面：L′ = L + F

光走過距離 d（介質 n）後：L₂ = L₁′ / (1 − (d/n)·L₁′)

總放大率：M = M₁ × M₂
