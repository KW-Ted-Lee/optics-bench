Chapter 02

球面折射

Refraction at Spherical Surfaces

角膜就是一個會聚的球面。一個彎曲的界面會讓不同高度的光線轉不同角度，於是平行光被聚到一點（或看起來從一點發出）。

學習目標 GOALS

  • 能從「形狀」與「兩側折射率」一起判斷球面是會聚還是發散。
  • 能說出第一焦點 F 與第二焦點 F′ 的定義，並理解兩者到表面的距離不必相等。
  • 能用光線追跡判斷像是實像或虛像、正立或倒立。

核心觀念 KEY IDEAS

Converging vs. Diverging

會聚或發散，要看兩件事

表面凸向哪一邊，加上光是從低折射率進入高折射率，還是反過來。凸面不一定會聚！

Secondary focal point F′

第二焦點 F′

平行光（來自無限遠）經過表面後聚焦的點；發散面則是平行光「看起來」發出的點。

Primary focal point F

第一焦點 F

從 F 發出（或朝向 F）的光，經過表面後變成平行光。F 與 F′ 的距離不同，因為兩側折射率不同。

Real vs. Virtual image

實像與虛像

由會聚光形成的是實像，倒立、可投影在屏幕上；由發散光「延長線」形成的是虛像，正立、看得到但投影不出來。

一個「凸面」，左邊是水（1.333）、右邊是空氣（1.000）。平行光由左射入，它會？

光從高折射率進入低折射率，凸面反而讓光發散。把左側設為「水」、右側設為「空氣」驗證看看。會聚或發散不能只看形狀。

觀察重點

  • 半徑越小（越彎），屈光力越強，F′ 越靠近表面。
  • 兩側折射率相同時屈光力為 0：再彎的表面也不會折射光。
  • F 與 F′ 在表面兩側，距離不相等；右側折射率較高時，F′ 比 F 遠。

物體越來越靠近表面、越過第一焦點 F 之後，像會變成？

物體在 F 以內時，折射後的光仍然發散，只能往回延長相交，形成正立、放大的虛像。物體剛好在 F 上時，射出的是平行光，像在無限遠。

觀察重點

  • 這裡使用 n = 1.000 → 1.500、半徑 +10 cm 的會聚面（+5.00 D）。
  • 實像一定在表面右側（光真的到那裡）；虛像在左側，用虛線表示光的延長線。
  • 物體靠近 F 時，像會跑得非常遠、非常大。

常見迷思 MISCONCEPTIONS

凸面一定會聚，凹面一定發散。
還要看折射率：光由高 n 進入低 n 時（例如由水進入空氣），凸面會發散、凹面會會聚。屈光力的正負同時由 (n′ − n) 和 r 決定。
F 和 F′ 一定在表面兩邊相同距離的位置。
只有兩側是同一種介質（例如空氣中的薄透鏡）才會相等。單一球面兩側折射率不同，焦距也不同。
虛像是「看不到」的像。
虛像看得到（放大鏡裡的字、鏡子裡的自己），只是不能投影在屏幕上，因為光線並沒有真的在那裡相交。

公式補充 OPTIONAL

展開看公式（選讀）

表面屈光力：F = (n′ − n) / r（r 以公尺計，曲率中心在右側為正）

焦距：f′ = n′ / F　f = −n / F
